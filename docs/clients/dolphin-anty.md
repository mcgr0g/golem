# Dolphin Anty

Читать, когда: настраиваешь профили браузера для западных AI-сервисов и биллинга.

- Dolphin использует локальный SOCKS5/HTTP прокси mihomo: `socks5://127.0.0.1:7897` (порт `mixed-port` пользователя). Профиль → «Прокси» → SOCKS5.
- Ожидаемый внешний IP профиля = IP VPS (проверить на сервисе проверки IP внутри профиля) либо IP static ISP прокси при цепочке.
- DNS: домены должны уходить в прокси необработанными (SOCKS5 domain), не резолвиться системой Mac.
- Утечки: проверка WebRTC (в Dolphin — режим подмены), DNS-leak тест, часовой пояс/язык профиля = регион IP.
- Один VPS = один IP: одновременная регистрация нескольких аккаунтов с одного IP повышает риск связки. Для этого — цепочка с static ISP прокси (на каждый профиль свой).
- Не проверено: поведение Dolphin при падении узла (разрыв vs прямое соединение) — проверить, что fallback на прямое выключен.
