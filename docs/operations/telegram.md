# Telegram: бот и chat_id

Читать, когда: настраиваешь уведомления (ram-alert, Gatus, сообщение об установке Gatus).

Значения `telegram_bot_token` и `telegram_chat_id` — в общих секретах (`mise secrets:edit common`, см. `secrets.md`).

1. Токен: создать бота у @BotFather, скопировать токен.
2. Написать боту `/start` (бот не может писать первым).
3. chat_id — ваш личный ID пользователя, не ID бота (ошибка при первой настройке: ID бота даёт ответ 403 «bot can't send messages to the bot»). Как узнать в клиенте Telegram: Настройки → Продвинутые → Экспериментальные настройки → включить «Показывать ID объектов в профиле» (Show Peer IDs in Profile); в профиле своего аккаунта появится строка «ID пользователя» (Peer ID) — скопировать.
4. Записать в секреты: `telegram_chat_id` строкой.

Сообщения: ram-alert и установка/обновление Gatus содержат имя хоста (`inventory_hostname`); имена проверок Gatus начинаются с имени хоста, поэтому алерты Gatus тоже его содержат.

Проверено на stage: сообщение об установке Gatus доставлено. Не проверено: алерт Gatus о падении сервиса и ram-alert (воспроизведение рискует блокировкой бота).
