# 0002 — Debian 12, не Ubuntu

Статус: принято.

## Контекст
Для Go-бинарников и Caddy/Xray разницы между Debian и Ubuntu нет. Ubuntu server потребляет больше (snapd, cloud-init-агенты в большинстве образов).

## Решение
Debian 12 (bookworm), minimal-образ провайдера. Debian 13 допустим, когда у провайдера появится стабильный образ; роли не должны зависеть от версии. В старом черновике встречались «Debian 12» и «Debian 13» — актуально 12.

## Последствия
Ansible использует `ansible.builtin.apt`, `systemd`; никаких snap. Тест на Lima — шаблон Debian 12.

## Пересмотреть
Если провайдер предлагает только Ubuntu: роли переносимы (проверить apt-репозитории Caddy).
