# 0007 — Вырезано из исходного черновика

Статус: принято.

| Что | Почему вырезано |
| :--- | :--- |
| Gost + ShadowTLS (`/api/v1/*`) | ShadowTLS сам завершает TLS-handshake и не живёт за Caddy на том же :443 по пути; лишний процесс; есть Xray WS. Резервный канал — второй VPS с тем же набором. |
| Uptime Kuma | Измерено: RSS 175–181 MB, ~580 MB диска вместе с Node 22, нет файла конфигурации. Заменён Gatus (ADR 0011). |
| 3x-ui и прочие панели | ADR 0003. |
| Сборка на VPS (`bun install && build`, `xcaddy`) | ADR 0009. |
| cron `* * * * *` с `>/dev/null 2>&1` | Нарушает запрет глушить ошибки; используем systemd timers + journald. |
