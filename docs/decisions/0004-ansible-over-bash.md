# 0004 — Ansible вместо bash

Статус: принято.

## Контекст
2–3 идентичных VPS, отличаются домен и секреты. Нужна идемпотентность, секреты в sops (ADR 0010), проверка на Lima, режим `--check --diff`.

## Решение
Ansible (control node — Mac, уже установлен через mise). Один набор ролей; различия — в `inventories/<env>/host_vars/<host>.yml` и sops. Bash допустим только как тонкие обёртки (`make`/скрипты сборки артефактов на Mac).

## Последствия
- На VPS нужен python3 (ставится на первом шаге через `raw`).
- Агентный запуск на VPS не нужен (agentless), RAM не расходуется.
- Структура: `operations/ansible-layout.md`.

## Пересмотреть
Если число хостов станет 1 и поддержка Ansible перевесит пользу.
