# 0014 — Bootstrap-only конфиг cliproxyapi

Статус: принято (выбор владельца 2026-11-06)

## Контекст
Ранее Ansible при каждом `site.yml` рендерил `/etc/cliproxyapi/config.yaml` из SOPS (`named_keys`, `mgmt_hash`). Это делало невозможным оперативный отзыв ключей без age и деплоя: панель не могла сохранить изменения (конфиг `root:cliproxyapi 0640`, `ProtectSystem=strict`). При компрометации ключа нужно было: расшифровать SOPS на Mac с age, изменить, применить Ansible — минимум несколько минут и доступ к Mac с age-ключом.

## Решение
Конфиг создаётся один раз (`force: false`) в `/var/lib/cliproxyapi/config.yaml` (owner `cliproxyapi`, `0600`). CPA имеет `ReadWritePaths` на этот каталог и может сохранять изменения через панель. Ansible больше не перезаписывает конфиг — только устанавливает бинарник, юнит и панельный HTML. Ключи доступа управляются через панель CPA; начальный набор из SOPS создаётся при bootstrap и доступен в `cpa-keys.txt`. Новые ключи — `mise run cpa:genkey` + ввод в панели. Отзыв — удаление в панели без деплоя и age.

## Последствия
- Ротация клиентских ключей CPA больше не требует age, sops и прогона Ansible.
- `secrets:rotate llm/key <имя>` и `secrets:keys` убраны.
- `cpa-keys.txt` актуален только для начальных bootstrap-ключей; после изменений через панель он устаревает.
- Новые параметры конфига (например `keepalive_seconds`) при изменении переменной Ansible не применяются автоматически; нужен ручной пересмотр конфига на сервере или пересоздание (с потерей добавленных через панель ключей — поэтому сначала сохранить ключи).
- Пустой список ключей в CPA = fail-open (запросы без авторизации проходят); при отзыве последнего ключа заменить на нераспространяемый, а не очищать список.
- Конфиг на сервере содержит ключи доступа; снапшоты VPS и бэкапы `/var/lib/cliproxyapi` хранят их в открытом виде.

## Пересмотреть
Если потребуется автоматическое применение параметров конфига без пересоздания ключей (например при смене keepalive) — рассмотреть разделение владения полями с защитой от гонок через `If-Match`.
