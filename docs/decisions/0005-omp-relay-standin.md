# 0005 — omp relay = заглушка local-relay.ts + статика

Статус: принято (выбор пользователя).

## Контекст
Прод-relay omp (Go) не публикуется. В oh-my-pi есть `packages/collab-web/scripts/local-relay.ts` (WS-only, `/r/<room>`, :7466, без auth, не раздаёт клиент, нет `/healthz`) и сборка веб-клиента в статический `dist/`. Альтернатива — сторонний `andrewleech/omp-connected` (hub с токеном): больше кода и стороннее обслуживание.

## Решение
Заглушка за Caddy + статика `dist/`, собранные на Mac. Зависимость от внутренних скриптов omp принимается; версия пинится по git-тегу oh-my-pi. Протокол relay не проверяет авторизацию, трафик шифруется end-to-end.

## Последствия
- Q1, Q2 закрыты экспериментом (relay компилируется в бинарник, клиент работает под префиксом); см. `components/omp-relay.md`.
- Нет `/healthz`: проверка живости — TCP-проба порта 7466 и WS-handshake.
- Защита: ADR 0006.

## Пересмотреть
Если upstream опубликует production relay — заменить заглушку.
