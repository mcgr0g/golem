# 0008 — C4 в Mermaid внутри docs/architecture

Статус: принято.

## Контекст
ASCII-схема из черновика не масштабируется. Нужна нотация, читаемая агентом как текст и рендерящаяся в GitHub/IDE.

## Решение
C4 Model на синтаксисе Mermaid (`C4Context`, `C4Container`, `C4Deployment`) + `sequenceDiagram`/`flowchart` для потоков. Один уровень — один файл в `docs/architecture/`; L1 дублируется кратко в `agents_bootstrap.md`. Единственный источник правды по маршрутам — таблица в `02-containers.md`.

## Последствия
- Мermaid C4 помечен экспериментальным: раскладка может быть неидеальна, смысл важнее картинки.
- L3 (Components) не ведём, пока компонент не усложнится — детали в `docs/components/`.

## Пересмотреть
Structurizr DSL — если моделей станет много и потребуется генерация видов из одной модели.
